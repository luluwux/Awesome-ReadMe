# 🤝 Awesome-ReadMe'ye Katkıda Bulunmak

Öncelikle, bu projeye katkıda bulunmayı düşündüğünüz için teşekkür ederiz! Bu depo, topluluk için kapsamlı bir kaynak olmayı hedefliyor ve katkılarınız bu kaynağın büyümesine yardımcı oluyor.

## 🚀 Profilinizi Galeriye Nasıl Eklersiniz?

Yaratıcı ve profesyonel GitHub profillerini sergilemeyi seviyoruz. Kendi profilinizi `_Examples` galerimize eklemek için lütfen şu adımları izleyin:

### 1. Depoyu Fork'layın (Çatallayın)

Sayfanın sağ üst köşesindeki **Fork** butonuna tıklayarak deponun kendi GitHub hesabınızda bir kopyasını oluşturun.

### 2. Profil Dosyanızı Oluşturun

Fork'ladığınız depoda `_Examples` dizinine gidin ve tam olarak GitHub kullanıcı adınızla adlandırılmış **yeni bir Markdown dosyası** oluşturun:
`_Examples/[Kullanıcı-Adınız].md` (örneğin, `luluwux.md`).

### 3. Şablonu Kullanın

Aşağıdaki şablonu kopyalayıp yeni dosyanıza yapıştırın ve bilgilerinizi doldurun.

> [!IMPORTANT]
> Lütfen README kodunuzun **tamamını** buraya yapıştırmayın. Sadece aşağıda gösterildiği gibi bağlantıyı ve kısa bir açıklamayı ekleyin.

```markdown
### [GITHUB KULLANICI ADINIZ]

**Profil Bağlantısı:** `https://github.com/[GITHUB KULLANICI ADINIZ]`

**Kısa Açıklama:**
[Profilinizin temel özelliklerini veya teknoloji yığınınızı (stack) anlatan 1-2 cümlelik açıklama.]

---

```

### 4. Pull Request (PR) Gönderin

* Değişikliklerinizi kaydedin: `git commit -m 'Add [Kullanıcı-Adınız] to examples'`.
* Fork'unuza push yapın ve bir **Pull Request (PR)** açın.

## 🌍 Çeviriler ve Yeni Diller

Bu çok dilli bir proje olduğu için çeviri katkılarına büyük değer veriyoruz!

* **Mevcut Çevirileri Geliştirmek:** `EN/` veya `TR/` klasörlerinde bir hata bulursanız veya bir şeyi ifade etmenin daha iyi bir yolunu biliyorsanız, PR göndermekten çekinmeyin.
* **Yeni Bir Dil Eklemek:**

1. Kök dizinde ISO dil kodunu kullanarak yeni bir klasör oluşturun (örneğin; Fransızca için `FR/`, Almanca için `DE/`).
2. `EN/` klasörüyle aynı iç yapıyı takip edin (örneğin; `01 Metin Biçimlendirme`, `02 Yapı ve Gezinme`).
3. Markdown formatını ve teknik bağlantıları koruyarak rehberleri çevirin.
4. Ana `README.md` dosyasını yeni dil için bir rozet (badge) ekleyerek güncelleyin.

## 🛠️ Katkıda Bulunmanın Diğer Yolları

* **Rehberleri İyileştirme:** Mevcut biçimlendirme rehberlerine yeni ipuçları ekleyin veya yazım hatalarını düzeltin.
* **Yeni Şablonlar:** `07 GitHub Profile` bölümlerine yeni README şablonları önerin veya ekleyin.
* **Hataları Bildirin:** Bozuk bir bağlantı veya hata mı buldunuz? Lütfen [bir issue açın](https://www.google.com/search?q=https://github.com/luluwux/Awesome-ReadMe/issues).

## 📝 Katkı Kuralları

* **Tutarlılık:** Lütfen mevcut klasör yapısına ve adlandırma kurallarına uyun.
* **Saygı:** Diğer katılımcılara karşı saygılı olun. Daha fazla ayrıntı için `CODE_OF_CONDUCT.md` dosyamızı kontrol edin.
* **Dil İzolasyonu:** Rehber güncellemelerinin doğru dil klasörüne (`EN/`, `TR/`, vb.) yerleştirildiğinden emin olun.

GitHub profillerini daha "Harika" (Awesome) hale getirmemize yardım ettiğiniz için teşekkürler! 🚀
