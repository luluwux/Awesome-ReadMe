# 🤝 Contributing to Awesome-ReadMe

First of all, thank you for considering contributing to this project! This repository aims to be a comprehensive resource for the community, and your contributions help it grow.

## 🚀 How to Add Your Profile to the Gallery

We love showcasing creative and professional GitHub profiles. To add yours to our `_Examples` gallery, please follow these steps:

### 1. Fork the Repository

Click the **Fork** button at the top right of this page to create a copy of the repository in your own GitHub account.

### 2. Create Your Profile File

In your forked repository, navigate to the `_Examples` directory and create a **new Markdown file** named exactly after your GitHub username:
`_Examples/[Your-Username].md` (e.g., `luluwux.md`).

### 3. Use the Template

Copy and paste the template below into your new file and fill in your details.

> [!IMPORTANT]
> Please **do not** paste your entire README source code. Only provide the link and a brief description as shown below.

```markdown
### [YOUR GITHUB USERNAME]

**Profile Link:** `https://github.com/[YOUR GITHUB USERNAME]`

**Short Description:**
[A 1-2 sentence description of your profile, its key features, or your tech stack.]

---

```

### 4. Submit a Pull Request

* Commit your changes: `git commit -m 'Add [Your-Username] to examples'`.
* Push to your fork and open a **Pull Request (PR)**.

## 🌍 Translations & New Languages

Since this is a multi-language project, we highly value translation contributions!

* **Improving Existing Translations:** If you find an error or a better way to express something in the `EN/` or `TR/` folders, feel free to submit a PR.
* **Adding a New Language:**
1. Create a new folder in the root directory using the ISO language code (e.g., `FR/` for French, `DE/` for German).
2. Follow the same internal structure as the `EN/` folder (e.g., `01 Text Formatting`, `02 Structure & Navigation`).
3. Translate the guides while maintaining the Markdown formatting and technical links.
4. Update the main `README.md` to include a badge for the new language.



## 🛠️ Other Ways to Contribute

* **Improving Guides:** Add new tips or fix typos in existing formatting guides.
* **New Templates:** Suggest or add new README templates to the `07 GitHub Profile` sections.
* **Report Issues:** Found a broken link or an error? Please [open an issue](https://www.google.com/search?q=https://github.com/luluwux/Awesome-ReadMe/issues).

## 📝 Contribution Rules

* **Consistency:** Please follow the existing folder structure and naming conventions.
* **Respect:** Be respectful to other contributors. Check our `CODE_OF_CONDUCT.md` for more details.
* **Language Isolation:** Ensure guide updates are placed in the correct language folder (`EN/`, `TR/`, etc.).

Thank you for helping us make GitHub profiles more "Awesome"! 🚀
